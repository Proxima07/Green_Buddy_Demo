# GreenBuddy 展示指南

## 建議的 4 分鐘路線

| 時間 | 操作 | 想傳達的重點 |
|---|---|---|
| 0:00–0:25 | 歡迎頁 → 直接逛逛示範花圃 | 會說話、有表情的植物夥伴 |
| 0:25–1:10 | 首頁點波波 → 看四項指標 → 我澆水了 | 先看情緒、再看數據；照護後有回應 |
| 1:10–1:35 | 往下滑歷史曲線 → 切 7 天與溫度 | 狀態、理想範圍、趨勢與照護建議相連 |
| 1:35–2:00 | 我的 → 切遊戲任務／簡潔 | 同一個產品能用不同個性陪伴不同使用者 |
| 2:00–2:40 | 首頁加號 → 模擬掃描 → 配網 → 示範植株 | 無需真實硬體即可展示完整新增流程 |
| 2:40–3:15 | 選株 → 看推薦 → 寵物條件 → 收藏 | 從購買前就提供協助 |
| 3:15–3:40 | 花圃 → 陽台展開 → 邀請家人 | 以空間為單位管理，共同照護的構想 |
| 3:40–4:00 | 造型衣櫥 → 試穿 → 儲存 | 持續照顧帶來收集與陪伴感 |

前一天先用 `python start_demo.py --local-assets` 準備。現場用展示控制台重設資料後，重新走一次想展示的故事即可。不同網頁伺服器 IP／連接埠的 localStorage 不互通，請固定同一網址展示。

## 可以現場切換的故事

- **「它有點渴」**：控制台將波波設為口渴 → 點開詳細 → 澆水 → 回首頁確認任務完成。
- **「第一次接回家」**：註冊新帳號 → 空花圃 → 掃描設備 → 熱點配網 → 植物建檔。
- **「連不上也不慌」**：配網控制設為藍牙＋逾時 → 看排錯提示 → 改成功 → 重試。
- **「AI 不確定時」**：控制台開啟辨識信心度不足 → 使用示範植株 → 手動搜尋品種。
- **「同一盆，不同個性」**：在三套風格間切換，對照首頁、任務與植物說話語氣。
