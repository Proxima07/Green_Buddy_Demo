# GreenBuddy v1.0.0 驗證紀錄

測試日期：2026-09-22。使用 Chromium 133 / Playwright，以本機專案檔案回應靜態請求；外部 CDN 請求刻意阻擋，以驗證本機備援。沒有透過真實硬體、真實帳號或真實 API 進行測試。

以下 16 組流程已通過：

1. 歡迎頁、快速體驗，以及四個 JavaScript 套件的 CDN 失敗備援。
2. 澆水更新表情、土壤濕度與任務；重複記錄不重複增加 XP；刷新後保存；7 天與溫度曲線切換。
3. 主題跨頁保存、簡潔模式單欄植物與四數值、遊戲模式經驗條。
4. 配件試穿與保存、未解鎖配件顯示進度。
5. 任務略過及原因保存、離線任務模擬恢復、XP 正確。
6. 新增花圃、使用者輸入以文字呈現、環境曲線。
7. 自動推薦、寵物友善篩選、願望清單保存。
8. 完整五題問卷到推薦結果。
9. 通知開關、模擬推播與登出。
10. 註冊、密碼輸入遮眼、風格選擇與空花圃。
11. QR 編號深連結、熱點配網、成功、示範辨識、暱稱建檔。
12. 藍牙配網失敗、重試、成功；Wi-Fi 密碼未寫入 localStorage。
13. 實際圖片檔案預覽、辨識信心不足、手動搜尋、第二盆建檔。
14. 控制台切換七種植物狀態，對應任務一致。
15. 解除設備並移除植物與相關任務。
16. 12 個已登入可達頁面在 320px 與 390px 寬度無整頁水平溢出；歡迎頁另以桌面畫面檢查。

另外檢查 HTML 入口、引用檔案存在、JavaScript 語法、中文字型、桌面 1440px 的手機外框，以及增量 ZIP 工具的新增／修改／刪除判斷。

測試流程未出現未捕捉的 JavaScript 例外或缺少的本機資源。隨附畫面截圖與實際執行版本一致。

尚未在實體 iPhone Safari、Android 手機、真實藍牙與 Wi-Fi 設備上驗證。這些裝置功能本來即為模擬範圍；手機拍照是否開啟相機，由瀏覽器對 capture 屬性的支援決定。
