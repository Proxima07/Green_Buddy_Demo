# GreenBuddy v1.0.2：減少模擬手機的展示裝飾

適用基底：v1.0.1。此更新僅包含新增或修改的檔案，請先套用 v1.0.1 天數快轉更新。

## 本次調整

- 13 個 HTML 頁面移除模擬手機狀態列：固定的 9:41、訊號、Wi-Fi、電池圖示及假瀏海。
- 手機畫面直接從網站內容開始，重新調整頂部與歡迎頁高度，並保留裝置安全區域的留白。
- 桌面版改為較輕的圓角內容面板，移除仿手機的厚邊框。
- 歡迎頁移除 DEMO 徽章，「我的」頁底部改為 GreenBuddy 品牌名稱。
- 頂部通知的位置配合新的留白調整。

感測器本身的連線狀態、電量與照護數值仍是植物管理資訊；展示用資料的必要說明仍保留。右下角展示控制台與 v1.0.1 的天數快轉可繼續使用。

## 套用方式

1. 將 ZIP 解壓縮。
2. 將其中 `greenbuddy-demo` 資料夾的內容，覆蓋到目前專案根目錄。若原本資料夾名稱是 `GreenBuddy`，就將 `js`、`css`、HTML 等內容合併進該資料夾，請勿再巢狀放入一層 `greenbuddy-demo`。
3. 在原本頁面按 **Ctrl + F5** 強制重新載入即可。使用原來的網址與連接埠，既有瀏覽器資料便會延續。

本次不需清空資料、重新註冊或刪除任何舊檔，也未變更啟動方式。

## 修改範圍

- 根目錄 13 個 HTML：移除重複的系統狀態列。
- `css/base.css`：狀態列樣式清理、手機安全區域與內容高度、通知位置、桌面面板外觀。
- `js/pages/index.js`、`js/pages/settings.js`：簡化頁面上的展示標籤。
- `README.md`、本說明、`release-manifest.json`：版本與增量更新資訊。

## 本次確認

- 確認 13 個 HTML 共用外殼均已移除狀態列，原頁面載入入口保持完整。
- 在 Chromium 檢視 390px 手機歡迎頁、390px 手機首頁與 1280px 桌面首頁截圖。
- 320px、390px 與 1280px 首頁無水平溢出，頁面頂端與底部導覽正常。
- 歡迎頁可進入首頁，未出現 JavaScript 執行錯誤，天數快轉功能仍載入。
