# GreenBuddy Demo v1.0.1：照護天數快轉

適用版本：v1.0.0。此 ZIP 只包含本次新增或修改的檔案，需搭配原本完整專案使用。

## 套用更新

1. 將更新 ZIP 解壓縮。
2. 將 ZIP 內 `greenbuddy-demo` 資料夾的內容，複製到原專案根目錄，合併資料夾並覆蓋同名檔案。原專案根目錄就是包含 `start_demo.py`、`index.html`、`js`、`css` 的位置。
3. 若你的專案目前叫做 `GreenBuddy`，就覆蓋到該資料夾內，請勿再巢狀放入一層 `greenbuddy-demo`。
4. 保持原來的網址與連接埠，使用 `Ctrl + F5` 強制重新載入。若尚未啟動，照原方式執行 `start_demo.py`。

本次保留相同的瀏覽器資料格式與儲存鍵值，無須清除瀏覽器資料、重新註冊或重設展示資料。原本新增的植物、任務與造型會延續。

## 使用方式

1. 開啟右下角滑桿圖示的「展示控制台」。若未顯示，請在網址加上 `demo=1` 參數。
2. 在最上方「照護天數快轉」按 **＋1 天、＋7 天、＋30 天**，或輸入自訂增加量後按「增加天數」。自訂值接受 1～3650 的整數。
3. 畫面立即顯示連續照護天數、總陪伴天數、已解鎖數量與距離下一件天數造型的差距。
4. 關閉控制台，在造型衣櫥點選剛解鎖的配飾，再按「就穿這件」保存。

快轉會同步增加連續照護天數、總陪伴天數與目前每盆植物的天數，並視為今天已完成模擬照護，避免接著完成任務時被舊日期重設連續天數。它不會修改系統時間、不會自動完成任務或增加 XP；感測數值與歷史曲線也不會因此產生新資料。

| 連續照護天數 | 解鎖配飾 |
| --- | --- |
| 7 天 | 綠手指皇冠 |
| 14 天 | 暖暖圍巾 |
| 21 天 | 閃閃星光 |
| 30 天 | 晚安睡帽 |
| 45 天 | 月光晚安 |

**連續照護達到 45 天，即可解開所有以天數為條件的配飾。** 其餘配飾仍依衣櫥標示的任務數解鎖。這個操作只調整展示用進度；往後的日常任務仍依原有規則累積連續照護天數。

- `css/base.css`：控制台新增區塊的桌面與手機版型。
- `README.md`：補充操作與版本說明。
- `docs/UPDATE_v1.0.1.md`：本更新說明。
- `release-manifest.json`：更新檔案比對清單，供下一次增量打包使用。

不需刪除任何舊檔，也不需更新字型或第三方套件。

## 已驗證

- 三個快速按鈕與自訂天數均能生效，跨過 7／14／21／30／45 天門檻時即時解鎖。
- 新增天數保留已有植物名稱、配飾、任務與照護紀錄，任務數與 XP 不受快轉影響。
- 負數、小數、超出上限與空白輸入不能修改進度。
- 已解鎖配飾可試穿、保存；重新整理後進度與造型仍保留。
- 快轉後同一天完成任務，連續天數不會被重設或重複增加，任務仍正常給予 XP。
- 1280px 桌面、390px 與 320px 手機寬度下控制台無水平溢出；390px 與 320px 已檢視截圖。
- `demo=0` 隱藏展示入口；本次互動檢查未出現 JavaScript 執行錯誤。
