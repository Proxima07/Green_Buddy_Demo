# GreenBuddy Demo v1.0.0

一個以手機為主、可完整點擊操作的植物陪伴展示版。依附件 P0–P12 的規劃，實作 13 個 HTML 頁面、三套風格、四種植物、七種表情與模擬資料流程。

## 1. 解壓與啟動

請先完整解壓縮 ZIP。入口在 `greenbuddy-demo/index.html`，不要只複製單一 HTML。

**Windows，電腦已安裝 Python 3：** 雙擊 `start_demo.bat`，會啟動本機網頁並開啟瀏覽器。

**跨平台：** 在 `greenbuddy-demo` 資料夾執行：

```bash
python start_demo.py
```

macOS / Linux 也可以使用 `python3 start_demo.py`。預設開啟：

```text
http://127.0.0.1:9002/index.html?demo=1
```

終端機保持開啟；結束時按 Ctrl+C。連接埠已被占用時：

```bash
python start_demo.py --port 9003
```

也可沿用 Python 原生靜態伺服器，不需安裝任何套件：

```bash
python -m http.server 9002 --bind 127.0.0.1
```

然後開啟 `http://127.0.0.1:9002/index.html?demo=1`。

### 完全不使用 CDN

套件、圖示與中文字型都隨檔附上。預設 JS 先嘗試固定版本 CDN，逾時或失敗便改載入本機備份；CSS、圖示字型與中文字型直接使用本機檔案。現場無網路可直接啟動：

```bash
python start_demo.py --local-assets
```

或在網址加上 `&assets=local`，略過 CDN 等待。這表示本機伺服器提供完整靜態檔案，不代表已實作 Service Worker 離線快取。

### 用手機展示

在可信任的同一 Wi-Fi 環境，可自行執行：

```bash
python start_demo.py --host 0.0.0.0 --no-browser --local-assets
```

在手機開啟 `http://電腦的區網IP:9002/index.html?demo=1&assets=local`。Windows 防火牆需允許此連接埠。一般電腦單機展示仍建議使用預設 127.0.0.1。

直接雙擊 `index.html` 可預覽，但各瀏覽器對 `file://` 的跨頁 localStorage 行為不一致，完整流程請使用上述 HTTP 啟動方式。

## 2. 快速看見成果

1. 歡迎頁按「直接逛逛示範花圃」，即可使用預設四盆植物。
2. 首頁點「波波」→「我澆水了」，查看表情、土壤數值、任務與歷史曲線改變。
3. 底部「我的」切換陪伴／遊戲任務／簡潔，整站外觀與角色文案同步改變。
4. 點首頁加號，完成「綁定 → 配網 → 植物建檔」。可用「使用示範植株」快速完成。
5. 「選株」先依陽台模擬環境推薦；也可回答 5 題、篩選寵物友善植物、收藏願望清單。
6. 「造型衣櫥」選植物、試穿、按「就穿這件」。重整後會保留。

新註冊帳號會從空花圃開始；展示登入接受任意非空白帳密。密碼不會保存或傳送。若想恢復四盆初始資料，使用展示控制台的「重設全部展示資料」。

## 3. 展示控制台

網址加 `?demo=1` 後會出現滑桿圖示。開啟後可：

- 指定植物的 7 種表情：開心、口渴、過濕、偏暗、太熱、睡眠、離線。
- 切換三套風格，觸發模擬推播。
- 強制藍牙／熱點配網路線，指定成功／逾時。
- 開啟「辨識信心度不足」，示範手動品種搜尋。
- 展示空花圃，或重設全部展示資料。

展示模式會在同一分頁的頁面跳轉中保留。加 `?demo=0` 可暫時隱藏控制按鈕。QR 深連結：`add-device.html?d=GB-000123&demo=1`。裝置格式為 `GB-` 加六位數字，已綁定的裝置會被攔截。

首頁最多顯示 1 項優先任務，讓手機畫面保留更多位置給植物；「看全部」可看完整任務清單，符合規格「最多 3 項」的限制。

## 4. 功能與模擬範圍

| 功能 | 本版行為 |
|---|---|
| 13 個頁面、底部導覽 | 已實作；桌面置中手機外框，手機滿版 |
| 三套風格 | 配色、圓角、陰影、文案、經驗值介面同步切換 |
| 植物角色 | 4 種 SVG 造型 × 7 種表情；搖葉、眨眼、密碼遮眼 |
| 澆水與任務 | 更新同一份 localStorage；同一任務不重複發 XP |
| 其他照護 | 高溫／過濕／缺光任務完成後更新對應模擬讀值；離線任務模擬恢復連線 |
| 歷史曲線 | Chart.js，24 小時／7 天／30 天，四種指標，理想區間，模擬澆水後變化 |
| 配網 | 完整 UI 與成功／失敗分支，不呼叫真實藍牙或 Wi-Fi API |
| QR | 模擬掃描與裝置編號參數，不使用相機即時解碼 |
| 植株照片 | 可選本機圖片與手機拍照；只以 Object URL 預覽，不上傳、不保存照片 |
| AI 辨識 | 固定候選 92%／5%／3%，2 秒過場；提供手動搜尋 |
| 選株推薦 | 預設環境數據或五題問卷，以窗向、經驗、寵物條件選取示範組合 |
| 花圃 | 建立空間、展開植物與環境曲線、模擬邀請連結 |
| 通知 | 開關、提醒時段保存；測試橫幅可點擊進入植物；無背景排程推播 |
| 造型 | 18 個選項，5 個初始可用（含原貌）；依任務／連續天數解鎖 |
| PWA | 只有 iPhone 加入主畫面教學；未實作 manifest、Service Worker、Web Push |
| 後端與驗證 | 無 FastAPI、JWT、帳號隔離、真實家人共享或感測器串接 |

所有登入者共用這個瀏覽器內的一份展示狀態；「註冊」會建立新的空展示狀態，並覆蓋先前的本機展示資料。登出只清除登入狀態。若 localStorage 被封鎖，資料無法跨頁可靠保存。

套件失敗時會讀取隨附備份；若連備份也缺檔，輪播與提示有基本降級，圖表則顯示明確提示。請保留完整資料夾。

## 6. 後續只交付更新內容

這次是第一次交付，因此提供完整 `GreenBuddy_Demo_v1.0.0.zip`。
後續修改以這版為基準，只打包變動檔案，路徑仍保留 `greenbuddy-demo/…`，並附更新清單。把更新 ZIP 解壓到原資料夾的上一層，合併同名資料夾即可；不需重新下載未變動的字型與套件。

若自己修改程式，也可使用附帶工具。請保留原版 `release-manifest.json`，完成修改後執行：

```bash
python tools/make_patch.py --baseline release-manifest.json --version 1.0.1 --out ../GreenBuddy_Demo_v1.0.1_patch.zip
```

工具會先讀取舊清單，再比較目前檔案，只把變更檔案與新版清單放入 ZIP，並更新本機清單。若有刪除檔案，會記錄在 `PATCH_NOTES.md`，不會自動刪掉使用者檔案。請先備份原專案；補丁要依版本順序套用。

若之後需要我協助更新，請提供這份 ZIP 或最新專案，以及要調整的頁面／功能，方便精準比對。
